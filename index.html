BIFRÖST: 3D-Aware Image Compositing with Language Instructions

📄 Paper (arXiv) 💻 Code 🤗 Models

BIFRÖST performs 3D-aware image compositing with language instructions, handling complex spatial relationships like occlusion and depth blur.

Abstract

This paper introduces Bifröst, a novel 3D-aware framework that is built upon diffusion models to perform instruction-based image composition. Previous methods concentrate on image compositing at the 2D level, which fall short in handling complex spatial relationships (e.g., occlusion). Bifröst addresses these issues by training MLLM as a 2.5D location predictor and integrating depth maps as an extra condition during the generation process to bridge the gap between 2D and 3D, which enhances spatial comprehension and supports sophisticated spatial interactions.

Our method begins by fine-tuning MLLM with a custom counterfactual dataset to predict 2.5D object locations in complex backgrounds from language instructions. Then, the image-compositing model is uniquely designed to process multiple types of input features, enabling it to perform high-fidelity image compositions that consider occlusion, depth blur, and image harmonization. Extensive qualitative and quantitative evaluations demonstrate that Bifröst significantly outperforms existing methods, providing a robust solution for generating realistically composited images in scenarios demanding intricate spatial understanding.

Method

BIFRÖST pipeline: (1) MLLM predicts 2.5D locations from language instructions, (2) Image compositing model generates realistic compositions considering 3D spatial relationships.

🎯 2.5D Location Prediction

We fine-tune a Multi-modal Large Language Model (MLLM) with a custom counterfactual dataset to predict accurate 2.5D object locations from natural language instructions.

🎨 3D-Aware Image Compositing

Our compositing model processes multiple input features including depth maps, enabling high-fidelity image generation that handles occlusion, depth blur, and harmonization.

🧠 Spatial Understanding

By bridging 2D and 3D representations, BIFRÖST achieves superior spatial comprehension and supports sophisticated spatial interactions in complex scenes.

Results

Quantitative Comparison

BIFRÖST significantly outperforms existing methods across multiple evaluation metrics.

Diverse Applications

Our method enables various creative applications with realistic 3D-aware compositions.

Ablation Analysis

Comprehensive ablation studies validate the importance of each component in our framework.
